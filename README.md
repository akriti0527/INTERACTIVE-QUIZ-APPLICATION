## This quiz application is built using HTML, CSS, and JavaScript. The HTML (index.html) creates the structure: a title, a container for the question, answer buttons, a score display, and a "Next" button. The CSS (style.css) styles the app to make it visually appealing, with button states for correct and incorrect answers.

The JavaScript (script.js) powers the logic. It begins by defining an array of quiz questions, each with a question text and an array of answer options, each marked as correct or not. The startQuiz() function initializes the quiz, resetting the index and score. The showQuestion() function displays the current question and dynamically creates buttons for each answer. When a user selects an answer, the selectAnswer() function checks correctness, visually marks the buttons (green for correct, red for wrong), and disables all buttons to prevent multiple selections.

The "Next" button moves to the next question or shows the final score when the quiz is over. resetState() clears old answer buttons before loading new ones. Finally, showScore() displays the user’s final result and allows them to restart the quiz.

This code provides a clean, interactive quiz experience with instant feedback and score tracking.
